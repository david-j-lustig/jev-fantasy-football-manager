# Changelog

## 0.1.0 - 2026-09-18

- Python library and `jev-ff` CLI for Sleeper lineup, waiver, and trade recommendations.
- League scoring from Sleeper `scoring_settings` (not generic `pts_ppr`).
- Optional TypeSafe Jev overlay for injuries, start/sit, FAAB, and trade fairness.
- 24-hour on-disk cache for the NFL player map.
